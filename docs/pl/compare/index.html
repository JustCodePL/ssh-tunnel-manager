Menedżery tuneli SSH według sytuacji.

Tunelami SSH zarządza kilka dobrych narzędzi. Poniżej: kiedy które pasuje. Dane pochodzą z README lub strony w sklepie każdego projektu, sprawdzone 2026-10-29. Piszemy też, czego nie umiemy: obecnie obsługujemy tylko lokalne przekierowania portów (bez SOCKS i bez przekierowań zdalnych).

SSH Tunnel Manager (ta aplikacja)

GUI · Windows, macOS, Linux · MIT

Wybierz, jeśli chcesz trzymać tunele w standardowym ~/.ssh/config (aplikacja zapisuje bloki Host, nie tylko je czyta), mieć jedną aplikację z GUI na Windows, macOS i Linuxa, licencję MIT i brak konta.

Źródło: README · sprawdzone 2026-10-29

0fuz/ssh-tunnel-manager

Pasek menu · macOS · MIT

Wybierz na macOS, jeśli potrzebujesz SOCKS, przekierowań zdalnych, przyczyny awarii tunelu i ochrony przed konfliktem portów. Natywny Swift, MIT, własny plik JSON (tunnels.json), czyta aliasy z ~/.ssh/config.

Źródło: README · sprawdzone 2026-10-29

Loris Tunnel

GUI · macOS, Windows · Apache-2.0

Wybierz na macOS lub Windows, jeśli potrzebujesz SOCKS5, przekierowań zdalnych, pomiaru opóźnień i importu z komendy ssh. Wails, Apache-2.0, własny plik TOML. Brak wersji na Linuxa.

Źródło: README · sprawdzone 2026-10-29

boring

CLI · MIT

Wybierz, jeśli wolisz terminal i konfigurację TOML (~/.boring.toml na macOS i Windows), potrzebujesz gniazd Unix i instalacji przez brew install boring. Obsługuje przekierowania lokalne, zdalne i SOCKS5. MIT, wiersz poleceń.

Źródło: README · sprawdzone 2026-10-29

Core Tunnel

App Store · macOS 15+ · darmowa z zakupami w aplikacji

Wybierz na macOS 15 lub nowszym, jeśli chcesz aplikację z App Store z przekierowaniami lokalnymi, zdalnymi i dynamicznymi oraz obsługą kart, np. YubiKey (wg strony w sklepie). Darmowa z zakupami w aplikacji.

Źródło: App Store · sprawdzone 2026-10-29
