// PYTANIA I ODPOWIEDZI

FAQ

Najważniejsze informacje przed instalacją i pierwszym połączeniem.

Czy aplikacja wysyła moje dane lub klucze do chmury?+

Nie. Aplikacja działa lokalnie, bez konta i zewnętrznego serwera konfiguracji. Hasła do zaszyfrowanych kluczy trafiają do systemowego magazynu poświadczeń, a nie do plików aplikacji.

Gdzie są przechowywane tunele?+

W standardowym pliku ~/.ssh/config. Metadane aplikacji są zapisane jako komentarze, więc konfiguracja pozostaje czytelna dla innych klientów SSH.

Czy obsługiwane są ProxyJump i bastion hosty?+

Tak. Możesz używać zarówno ProxyJump, jak i ProxyCommand oraz kluczy RSA, ECDSA i Ed25519 — także zabezpieczonych hasłem.

Czy można bezpiecznie wrócić do starszej wersji?+

Tak. Zamknij aplikację, pobierz instalator lub archiwum z wybranego wydania powyżej i zainstaluj je ponownie. Przed rollbackiem warto zachować kopię ~/.ssh/config, szczególnie po dużej aktualizacji.

Jak działają aktualizacje?+

Aplikacja sprawdza GitHub Releases przy uruchomieniu i informuje o nowszym wydaniu. Aktualizację uruchamiasz samodzielnie z ustawień lub menu zasobnika.

Czy portless wymaga uprawnień administratora?+

Zwykłe tunele nie. Na macOS portless poprosi o jednorazową zgodę na wąskie przekierowanie PF dopiero przy porcie poniżej 1024. Na Linuksie taki port wymaga capability CAP_NET_BIND_SERVICE. Aplikacja pozostaje uruchomiona jako zwykły użytkownik i pokaże właściwy monit dla platformy.
