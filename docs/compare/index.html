SSH tunnel managers, by situation.

Several good tools manage SSH tunnels. Here is when each one fits. Details come from each project's own README or store page, checked on 2026-10-29. We list what we cannot do too: we currently support local port forwarding only (no SOCKS and no remote forwards).

SSH Tunnel Manager (this app)

GUI · Windows, macOS, Linux · MIT

Pick it if you want your tunnels stored in the standard ~/.ssh/config (the app writes Host blocks, not only reads them), one GUI app for Windows, macOS and Linux, the MIT license and no account.

Source: README · checked 2026-10-29

0fuz/ssh-tunnel-manager

Menu bar app · macOS · MIT

Pick it on macOS if you need SOCKS proxies, remote forwards, the reason a tunnel failed, and a guard against port conflicts. Native Swift, MIT, stores tunnels in its own JSON file (tunnels.json) and reuses host aliases from ~/.ssh/config.

Source: README · checked 2026-10-29

Loris Tunnel

GUI · macOS, Windows · Apache-2.0

Pick it on macOS or Windows if you need SOCKS5 and remote forwards, latency measurement, and importing tunnels from an ssh command. Built with Wails, Apache-2.0, stores its configuration in its own TOML file. No Linux build is listed.

Source: README · checked 2026-10-29

boring

CLI · MIT

Pick it if you prefer the terminal and a TOML configuration (~/.boring.toml on macOS and Windows), need Unix sockets, and like installing with brew install boring. It supports local, remote and SOCKS5 forwarding. MIT, command line.

Source: README · checked 2026-10-29

Core Tunnel

App Store · macOS 15+ · free with in-app purchases

Pick it on macOS 15 or later if you want an App Store app with local, remote and dynamic port forwarding and support for smart cards such as YubiKey (according to its store listing). Free with in-app purchases.

Source: App Store listing · checked 2026-10-29
