// QUESTIONS AND ANSWERS

FAQ

The essentials before installation and your first connection.

Does the app send my data or keys to the cloud?+

No. The app runs locally, without an account or external configuration server. Passwords for encrypted keys go to the operating system credential store, not to the app's files.

Where are tunnels stored?+

In the standard ~/.ssh/config file. App metadata is stored as comments, so the configuration remains readable by other SSH clients.

Are ProxyJump and bastion hosts supported?+

Yes. You can use ProxyJump and ProxyCommand as well as RSA, ECDSA, and Ed25519 keys — including password-protected keys.

Can I safely return to an older version?+

Yes. Quit the app, download an installer or archive from the selected release above, and install it again. Before rolling back, keep a backup of ~/.ssh/config, especially after a major update.

How do updates work?+

The app checks GitHub Releases on startup and lets you know when a newer release is available. You start the update yourself from settings or the tray menu.

Does Linux require administrator privileges?+

Regular tunnels do not. Additional authorisation is only needed for portless binds that use privileged ports below 1024. The app will show the relevant instructions.
