v1.2.0-beta.8 BETA 25 November 2026

Faster screen sharing with a Mac

The screen of a Mac now follows clicks and typing faster, because the Mac sends it in 16-bit colour, and the pointer no longer disappears.

16-bit colour for a Mac

macOS Screen Sharing sends its whole Retina screen again for small changes, such as a blinking caret, so the amount of data decides how fast the screen follows input. The app now asks a Mac for 16-bit colour, which is about half the data, and converts it for the viewer. Against a Mac on macOS 13.7 over Wi-Fi through SSH, a full screen went from 1.48 MB to 0.68 MB, and the screen updated 26 times in 6 seconds instead of 12. Other VNC servers keep sending full colour. A full color button in the toolbar switches that Mac back to every colour; it reconnects, the button then reads 16-bit color, and the choice is remembered for that tunnel and forward.

A pointer that stays visible

A Mac sends the pointer's shape only once the pointer moves, and hides the pointer while you type. When the server shows no pointer, the viewer now shows a dot instead of nothing. This applies to every VNC server.

How to use it

  • Nothing to do: screen sharing with a Mac uses 16-bit colour by default.
  • To see every colour, click full color in the screen sharing toolbar. Click 16-bit color to go back.

Known limits

  • The app converts the screen on your computer, which takes CPU time: about 77 ms per full screen on an Intel Mac.
  • The screenshot comes from the test build, against the test server, which shows a single colour instead of a desktop. The speed was measured against one Mac on macOS 13.7; the button and the dot pointer were tested only against the test server.
  • The limits of the previous beta still apply.
