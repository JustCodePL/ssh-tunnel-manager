Built-in SFTP file editing

Text, config and source files open from the SFTP browser straight into a built-in editor.

The editor

It is based on CodeMirror, with syntax highlighting for common web and DevOps formats. Files load and save over SFTP with no local temp copies. Unknown formats can be forced open as plain text. You can edit next to the file list or pop the editor out into its own window, with minimize, as with the terminal.

Saving

If the file changed on the server since you opened it, the app warns before overwriting. Writes are atomic and keep the file's permissions. Switching to another file with unsaved changes asks whether to save, discard or cancel.

Auto-connect on startup

Tunnels flagged to connect on startup now connect when the app launches.
