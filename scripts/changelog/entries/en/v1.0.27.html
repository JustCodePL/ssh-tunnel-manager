Privileged Portless ports on Linux

On Linux, portless forwards on privileged ports such as :80 now work. macOS and Windows are unaffected.

A clear error and a one-click fix

These forwards used to fail silently because the process lacked CAP_NET_BIND_SERVICE. The only trace was a buried log line. The app now detects this and shows an in-app banner and a desktop notification with the exact setcap command for your binary. The auto-updater re-applies the capability after replacing the binary. Packagers get a PolicyKit policy file, and the README has a section on portless mode on Linux.

How to use it

  • Click [ AUTHORIZE ], which uses PolicyKit and pkexec setcap.
  • Click [ RESTART NOW ] to apply it.
