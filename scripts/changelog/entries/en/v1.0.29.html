Live remote host monitoring

A connected tunnel shows live data from the remote host. Stats go over the existing SSH connection, with no extra connections or agents on the remote.

CPU and RAM

A compact usage bar appears under the host on every connected tunnel.

Disk

The disk button opens a window listing all mounts with usage bars.

Docker and htop

On hosts where docker is detected, the docker button opens a live container view. On hosts where htop is detected, the htop button opens a graphical monitor with per-core CPU bars, RAM and swap, load average, uptime and the top processes. term still gives you a full shell. Detected tools are remembered per host, so the buttons stay visible across app restarts, disabled until you reconnect. Clicking one re-checks the tool and tells you if it's no longer installed.

How to use it

  • Turn the CPU and RAM widget on or off in Settings, in the monitoring section.
  • Click disk, docker or htop on a connected tunnel.
