v1.0.28 STABLE 3 June 2026

Safer Portless defaults and reliable Linux updates

The Host header rewrite on portless forwards is now opt-in, and after an update on Linux the new version runs.

Host header rewrite is opt-in

For portless forwards the rewrite is off by default and applies only when you enable it per forward, in the forward settings (⚙). The previous automatic rewrite on FQDNs broke plain TCP and other non-HTTP services. Configs that set an explicit value keep working.

Updates on Linux

After installing an update the app relaunches into the new binary, as on macOS and Windows. Before this, the old version kept running after Install & Restart.
