v1.0.22 STABLE 27 May 2026

SFTP browser and unified overlay windows

You can browse remote files over SFTP, and logs and the tunnel form now open in the same kind of window as the terminal.

SFTP file browser

Browse remote filesystems, with concurrent uploads and downloads.

Overlay windows

Logs and the new and edit tunnel form use the same overlay as the terminal and file browser: a titlebar with minimize and close, a restore pill in the bottom-right corner, and a scrollable body that adapts when the window is resized. The terminal refits whenever the window is resized. Logs stay at the bottom on resize when auto-scroll is active.
