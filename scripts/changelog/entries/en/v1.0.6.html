v1.0.6 STABLE 3 March 2026

Tunnel logs and safer authentication failures

Each tunnel gets its own log viewer, and failed authentication no longer starts a reconnect loop.

Tunnel logs

A new log viewer shows the log of a single tunnel.

Authentication failures

Auto-reconnect stops on SSH authentication failures, so the app doesn't hammer the server with bad credentials. The Windows tray icon size is also fixed.
