v1.0.16 STABLE 12 March 2026

SSH config includes and better startup behavior

The app reads Include directives from ~/.ssh/config, and you can choose what the close button does.

Include directives

Include in ~/.ssh/config is supported, and the UI groups hosts by source file.

Close button

The close button can either minimize to the tray or quit the app.

Windows autostart

The exe path is quoted in the registry, and there is a new --hidden startup flag.
