v1.0.0 STABLE 2 March 2026

First public release

The first public release of SSH Tunnel Manager, a desktop app for managing SSH tunnels on Windows, macOS and Linux.

Tunnels and config

SSH runs in pure Go (golang.org/x/crypto/ssh), so no system ssh binary is required. The app reads and writes Host blocks in ~/.ssh/config and keeps its own metadata in comments that survive each save. Local port forwarding is included.

System tray

The tray is the primary interface, with a status badge and colored indicator dots.

Installing and updating

The app updates itself from GitHub Releases. Windows has an NSIS installer.
