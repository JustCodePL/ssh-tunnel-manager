Portless .ssh-local domains

A forward can get its own name under .ssh-local instead of a port on 127.0.0.1.

Portless mode

With the portless toggle on, a forward gets a dedicated 127.0.1.x loopback IP and is published as <domain>.ssh-local through a DNS server built into the app. If the address is in use, the next IP is tried. An optional exposed port sets what the clipboard and tray give you: an http:// or https:// URL when bound to 80 or 443, otherwise host:port.

One-time admin setup

Each platform needs it once: an NRPT rule on Windows, /etc/resolver on macOS, a systemd-resolved drop-in on Linux. The app asks for it on the first portless connect.

Form and tunnel cards

Each forward has its own block in the edit form, with the description on top. Clicking a forward tag on a tunnel card copies the address and shows a toast. Editing a connected tunnel reconnects it live.
