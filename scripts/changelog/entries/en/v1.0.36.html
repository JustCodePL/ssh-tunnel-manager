v1.0.36 STABLE 31 August 2026

Reliable Portless, updates, and background operation

This stable release brings the changes tested in the v1.0.32 to v1.0.36 beta series.

macOS updates

Updates work across DMG paths, bundle-name migrations, switches from Beta to Stable, and app installations owned by another administrator account.

Portless

Automatic forwards are preserved and SSH forwarding errors are clearer. macOS supports privileged port 80. A shared DNS registry handles simultaneous user sessions.

Running in the background

The app starts quietly on login and pauses resource polling while hidden. ProxyCommand started from Finder or a LaunchAgent can reach common helper locations again.
