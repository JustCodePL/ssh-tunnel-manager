Persistent Portless on macOS and a notarized app inside the DMG

On macOS 13+ Portless keeps working after a reboot, once you approve a signed system service.

Portless system service on macOS

The service restores DNS, loopback aliases and forwarding on privileged ports at boot, for every macOS account. If its registration goes stale, the app shows a recovery hint. Local ports remain as a fallback.

Logs, updates and the DMG

Application logs go to a private file with bounded rotation, also for background launches. The app relaunches reliably after an update when it was started at login. The macOS app inside each DMG carries its own stapled notarization ticket. In the port forwarding form, the add action sits below the list.

How to use it

  • On macOS 13+, approve the signed Portless system service once.
  • Inspect, refresh or remove the service in Settings.
