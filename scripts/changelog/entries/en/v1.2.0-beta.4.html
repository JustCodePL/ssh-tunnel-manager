v1.2.0-beta.4 BETA 4 November 2026

The system title bar on macOS

On macOS the main window now has the real window buttons, on the left, in a bar that takes the colour of your theme.

Real window buttons

The main window used to draw its own buttons on the right. It now keeps the system title bar, so closing, minimizing, zoom, the menu on the green button, full screen and dragging are the ones you know from other Mac apps. The bar takes the colour of the theme in every window and changes as soon as you switch themes. Windows and Linux stay as they were.

How to use it

  • Use the buttons on the left of the title bar, and drag the window by the bar.
  • Hold the pointer over the green button for the options to fill or tile the window.

Known limits

  • Dragging a window to a screen edge to tile it is a macOS 15 feature that needs its option turned on. It has not been tested with this app.
  • The main window title is now in the system font, so the [ SSH TUNNEL MANAGER ] label no longer appears on macOS.
  • The limits of the previous beta still apply.
