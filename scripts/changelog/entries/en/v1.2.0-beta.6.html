Screen sharing over VNC, for a Mac behind a tunnel

The screen of a Mac (macOS Screen Sharing) or of another VNC server now opens in a window of the app, through the SSH tunnel, like the built-in remote desktop.

VNC forwards and detection

A forward to port 5900, or one whose type is set to vnc, gets a VNC tag and an Attach button that opens the screen behind it. After connecting, the app also looks for a VNC server on the host's own port 5900; when it finds one, Screen sharing (VNC) appears under Attach, in the tray menu and in the command palette, and V opens it from the list.

Signing in to a Mac

A Mac takes the user name and password of an account on it (Apple Remote Desktop authentication). Other servers take a VNC password, or nothing. The app signs in itself and gives the viewer a session that needs no password, so a saved password never reaches the viewer. A login that worked can be saved in the system keychain, and the form offers every saved login. A rejected login says so, with the server's reason when it gives one, and a server that only accepts encryption the app does not support is named as such. The screen fits the window or shows at its real size, and the shared clipboard carries text in the direction set for the tunnel.

VNC in the tunnel's settings

The Credentials page of a tunnel has a VNC section: screen sharing on the host can be turned on or off whatever the detection found, and each target can have its own saved login. A login saved from a remote desktop or screen sharing window no longer overwrites a login the tunnel also uses for SSH; a new one is saved instead.

How to use it

  • On the Mac, turn on Screen Sharing in System Settings → General → Sharing, and allow your account.
  • Connect the tunnel to that Mac, then choose Attach → Screen sharing (VNC). For a Mac behind a bastion, add a forward to its port 5900 and use the forward's Attach.
  • Sign in with the Mac's account name and password. For a server with only a VNC password, leave the user empty.
  • Use actual size or fit to window in the window's bar to change the scale.

Known limits

  • Not yet tested against a real Mac with Screen Sharing. It was tested only against a test VNC server in the automated tests: the login, the password check and the picture. The Mac login, the keyboard (⌘, ⌥ and Polish letters), the clipboard and loading the viewer in the macOS desktop window are waiting for a manual test.
  • Servers that require encryption (VeNCrypt, TLS, RA2) are not supported.
  • Only port 5900 is checked on the host itself. A server on another port needs a forward of type vnc.
  • The screenshots come from the test build in a browser, not from the desktop window.
  • The limits of the previous beta still apply.
